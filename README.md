# MobileDock

iPhone / iPad を Mac の「3つ目の入力デバイス」にするローカルネットワーク・リモートです。
choclift と同じコンセプト（Mac 側のメニューバーアプリ + iOS/iPadOS 側のバー UI、PIN ペアリング）を、
独自実装・独自デザインで再現しています。

- **MobileDockMac** — メニューバー常駐の macOS ホストアプリ（Bonjour で待ち受け、実際の操作を実行）
- **MobileDock** — iPhone / iPad のリモートアプリ（ユニバーサル）

通信はすべて同一 Wi‑Fi 内の直接接続で、アカウントもクラウドも使いません。
接続は **TLS 1.2（PSK）で暗号化**され、鍵はペアリング PIN から導出します。PIN を知らない端末は TLS ハンドシェイクの時点で弾かれます。

## UI

ゲームパッドのホームメニュー風の「ボード」UI です（配色・質感はすべて自前のグラデーションと図形で描画。任天堂のアセットや商標は使用していません）。

- 明るいボードに白い光沢タイルが並ぶ、固定スロットのホーム画面（iPhone 縦 4×5 / 横 6×3、iPad 縦 6 列 / 横 8 列）
- 空きスロットは薄いプレートとして常時表示。ドラッグしたタイルは空きスロットに直接ドロップできる
- 上段: 左に接続中の Mac カード、中央に白い帯のページマーカー、右に編集 / 設定の丸ボタン
- 左右の端に大きな三角矢印（タップでページ送り。端では淡色で無効）
- 下段: 上辺が緩く弧を描くフッターバー。左に丸い DOCK ボタンと3つの小アイコン（Recents / Emoji / Clipboard）、中央に時計と日付、右に丸い全画面ボタン（時計は毎分更新、12/24時間制はロケールに追従）
- タイルは起動中を緑バッジ、最前面アプリを青いコーナーブラケットの選択枠で表示

## セットアップ

```bash
xcodegen generate          # project.yml から MobileDock.xcodeproj を生成
open MobileDock.xcodeproj
```

1. `MobileDockMac` スキームを Mac で実行 → メニューバーに アイコンが出ます。
2. 初回起動時のセットアップガイド、またはメニューバーのパネルに **6 桁の PIN** が表示されます。
3. `MobileDock` スキームを iPhone / iPad（実機またはシミュレータ）で実行。
4. 一覧から Mac を選び、PIN を入力すると接続完了。以降はトークンで自動再接続します。

### 必要な権限

- **アクセシビリティ**（Mac・必須）
  絵文字/テキスト入力、ウインドウの最小化・拡大、Mission Control などに必要です。
  未許可の場合はメニューバーのパネルとセットアップガイドに警告が出て、そこから
  「システム設定 → プライバシーとセキュリティ → アクセシビリティ」へ移動できます。
- **ローカルネットワーク**（iOS・初回接続時にダイアログ）

macOS 側は App Sandbox を無効にしています（他アプリの起動とイベント送出はサンドボックス下では行えないため）。

## 構成

```
Shared/                プロトコル（Codable メッセージ + 長さ prefix フレーミング）とテーマ
Mac/Sources/
  HostServer.swift     NWListener + Bonjour 広告、PIN ペアリング、複数端末の同時接続
  AppCatalogService.swift  アプリ走査・アイコン PNG 化・起動中/最前面/履歴の追跡
  ActionExecutor.swift 起動・終了・Shortcuts・URL・Unicode 入力・AX ウインドウ操作・メディアキー
  MenuBarPanel / WelcomeView / PreferencesView   メニューバー UI・セットアップ・設定
iOS/Sources/
  DockClient.swift     NWBrowser による探索、接続、トークン保存、状態同期
  DockStore.swift      ページとタイルの永続化（初回は Mac の履歴から自動生成）
  DockBarView.swift    メインのバー UI（iPhone: 下部モードバー / iPad: サイドバー）
  TileView.swift       タイル 1 個ぶんの見た目とジェスチャ
  Panels.swift         Recents / 絵文字 / クリップボード
  AddTileView / TileEditorView / DockSettingsView
```

### プロトコル

`ClientMessage` / `ServerMessage`（Swift の enum + associated value を Codable 化）を
4 バイトのビッグエンディアン長さ prefix + JSON で送受信します。サービス種別は `_mobiledock._tcp`。
ペアリングが成功すると Mac がトークンを発行し、端末はそれで自動再接続します。

## 動作確認済み

実機の Mac（このリポジトリのホスト）と iPhone 17 Pro / iPad Pro 11-inch シミュレータで、
Bonjour 探索 → PIN ペアリング → カタログ同期 → アプリ切り替え → 最前面アプリのライブ更新 →
クリップボード取得 → トークンによる自動再接続 → Dock only モード → ドラッグでの並び替えと再起動後の順序保持
まで確認しています（Dock only とドラッグ操作は iPhone シミュレータで実操作、iPad は同じコードパスを共有）。

絵文字入力・ウインドウジェスチャはアクセシビリティ権限が必要なため、権限付与後に実機で確認してください。
